### Это программа предназначенная для лаборантов ####
Эта программа меню которая показывает различную полезную информацию предназначенную для работы лаборанта.
Прежде чем запустить меню, программа требует ввести кол/во рабочих дней и ставку, а как проверку требует ввести длительность рабочего дня.
В самом меню 6 пунктов. В каждом пункте находится информация предназначенная для работы лаборанта. При выходе из меню программа требует ввести число рабочих часов на полставки. 
## Code Review & Vulnerability Analysis

### Уязвимость 1: Использование неинициализированных переменных

Описание проблемы:

В функции premenu() переменные workdays и workinghours используются до их инициализации:

double weekworkhours = workdays * workinghours;  // используются неинициализированные переменные!
const double standard_workinghours = 8.0;
cout << "Прежде чем прейти в меню, введите кол/во рабочих дней и ставку (0.5, 1.0, 1.5 и т.д).\n";
cin >> workdays >> stavka;  // инициализация происходит ПОСЛЕ вычисления выше

Тестовый ввод: Запуск программы >> переменные содержат случайные значения из памяти.

Потенциальные последствия:
- Крах программы из-за использования мусорных значений из памяти
- Невалидные расчеты рабочего времени и штрафов для лаборанта
- Непредсказуемое поведение при каждом запуске (значения в памяти различаются)
- Некорректные записи в системе учёта ВУЗа о рабочем времени
- Финансовые потери при начислении зарплаты и штрафов

Предлагаемое решение:

Инициализировать все локальные переменные перед использованием:

void premenu() {
    int workdays = 0;           // инициализация с 0
    double stavka = 0.0;        // инициализация с 0
    double workinghours = 0.0;  // инициализация с 0
    const double standard_workinghours = 8.0;
    
    cout << "Прежде чем прейти в меню, введите кол/во рабочих дней и ставку (0.5, 1.0, 1.5 и т.д).\n";
    cin >> workdays >> stavka;

    while (true) {
        cout << "Введите длительность рабочего дня в часах.\n";
        cin >> workinghours;
        double correctworkinghours = standard_workinghours * stavka;
        double weekworkhours = workdays * workinghours;  // теперь переменные инициализированы
        double correctweekworkinghours = correctworkinghours * workdays;
        // остальной код
    }
}

### Уязвимость 2: Отсутствие валидации потока ввода (cin errors)

Описание проблемы:

При вводе некорректных данных (буквы вместо цифр) функция cin не проверяется на наличие ошибок:

cin >> choice;      // если ввести "abc", флаг ошибки останется установленным
cin >> workdays >> stavka;  // последующие cin будут пропускать ввод
cin >> workinghours;

Тестовый ввод:
- Вместо цифры для choice вводим: "hello"
- Результат: программа игнорирует реальный ввод, зависает или работает с мусорными данными

Потенциальные последствия:
- Зависание программы в бесконечном цикле из-за некорректного состояния потока
- Некорректные расчеты часов и зарплаты лаборанта
- Отказ в обслуживании (DoS) - программа не может продолжить корректную работу
- Срыв расписания занятий - невозможно заполнить правильное рабочее время
- Финансовые потери при неправильном начислении оплаты

Предлагаемое решение:

Создать функцию безопасного ввода с проверкой статуса потока:

#include <limits>

int safe_input_int() {
    int value;
    while (!(cin >> value)) {
        cin.clear();  // очистить флаг ошибки
        cin.ignore(numeric_limits<streamsize>::max(), '\n');  // очистить буфер
        cout << "Ошибка! Введите корректное целое число: ";
    }
    return value;
}

double safe_input_double() {
    double value;
    while (!(cin >> value)) {
        cin.clear();
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
        cout << "Ошибка! Введите корректное число (например 0.5): ";
    }
    return value;
}

// В функции menu():
choice = safe_input_int();

// В функции premenu():
workdays = safe_input_int();
stavka = safe_input_double();
workinghours = safe_input_double();

### Уязвимость 3: Деление на ноль

Описание проблемы:

В функции premenu() при вычислении процента от нормы:

cout << "...составляют " << weekworkhours << " часов в неделю. Разница рабочего времени: " 
     << correctweekworkinghours - weekworkhours << " (" 
     << correctweekworkinghours/weekworkhours * 100 << "% от нормы ставки " << stavka << ").\n";

Если пользователь вводит 0 часов в день, то weekworkhours = 0, и произойдёт деление на ноль.

Тестовый ввод:
Рабочие дни: 5
Ставка: 0.5
Длительность дня: 0 часов
>> weekworkhours = 5 * 0 = 0
>> correctweekworkinghours / 0 = UNDEFINED BEHAVIOR

Потенциальные последствия:
- Неопределённое поведение (UB) - программа может вывести inf, nan, рухнуть или выдать случайные значения
- Ошибочные расчеты штрафов и зарплаты лаборанта (расчёт будет содержать бесконечность)
- Срыв учёта рабочего времени в системе ВУЗа
- Финансовые потери при попытке автоматической обработки таких данных

Предлагаемое решение:

Проверка знаменателя перед делением:

while (true) {
    cout << "Введите длительность рабочего дня в часах.\n";
    cin >> workinghours;
    double correctworkinghours = standard_workinghours * stavka;
    double correctweekworkinghours = correctworkinghours * workdays;
    double weekworkhours = workdays * workinghours;
    
    if (workinghours == correctworkinghours) {
        cout << "Данные введены правильно, приступайте к меню.\n" << endl;
        menu();
        break;
    } else {
        cout << "Ошибка! При " << workdays << "-дневной рабочей неделе " 
             << workinghours << " часа в день составляют " << weekworkhours 
             << " часов в неделю. Разница рабочего времени: " 
             << correctweekworkinghours - weekworkhours;
        
        // ПРОВЕРКА ПЕРЕД ДЕЛЕНИЕМ
        if (weekworkhours > 0) {
            double percentage = (correctweekworkinghours / weekworkhours) * 100.0;
            cout << " (" << percentage << "% от нормы ставки " << stavka << ").\n";
        } else {
            cout << " (невозможно вычислить процент: рабочее время нулевое).\n";
            cout << "Налицо факт предоставления заведомо ложных сведений работодателю. "
                 << "Попробуйте ввести снова.\n";
            continue;
        }
        cout << "Налицо факт предоставления заведомо ложных сведений работодателю. "
             << "Попробуйте ввести снова.\n";
    }
}

### Уязвимость 4: Отсутствие валидации диапазонов входных данных

Описание проблемы:

Программа не проверяет логические границы и реалистичность введённых значений:
- Отрицательное количество рабочих дней
- Отрицательное количество часов
- Нулевая или отрицательная ставка
- Неправдоподобная ставка (1000.0)
- Количество рабочих дней больше 7

cin >> workdays >> stavka;  // Пользователь вводит: -5, -0.5
// Программа продолжает работу с невалидными значениями!

Тестовый ввод:
Рабочие дни: -10
Ставка: -5.0
Часов в день: -8.0
>> weekworkhours = -10 * -8 = 80 (логически неправильно, но вычисляется)
>> Штраф считается на основе отрицательных значений
>> В базе данных ВУЗа появляются отрицательные часы

Потенциальные последствия:
- Некорректные финансовые расчеты - лаборант получит отрицательный штраф (возмещение вместо штрафа)
- Финансовые потери ВУЗа - ошибочное начисление зарплаты и штрафов
- Ошибки в бухгалтерской системе - отрицательные часы работы не имеют смысла
- Срыв расписания - данные теряют валидность в системе планирования
- Юридические проблемы при аудите финансовой отчётности ВУЗа

Предлагаемое решение:

Создать функцию валидации входных данных:

bool validate_input(int workdays, double stavka, double workinghours) {
    if (workdays <= 0 || workdays > 7) {
        cout << "Ошибка: Количество рабочих дней должно быть от 1 до 7.\n";
        return false;
    }
    if (stavka <= 0 || stavka > 2.0) {
        cout << "Ошибка: Ставка должна быть положительной и не превышать 2.0.\n";
        return false;
    }
    if (workinghours <= 0 || workinghours > 12) {
        cout << "Ошибка: Длительность рабочего дня должна быть от 1 до 12 часов.\n";
        return false;
    }
    return true;
}

// В функции premenu():
void premenu() {
    int workdays = 0;
    double stavka = 0.0;
    double workinghours = 0.0;
    const double standard_workinghours = 8.0;
    
    cout << "Прежде чем прейти в меню, введите кол/во рабочих дней и ставку (0.5, 1.0, 1.5 и т.д).\n";
    
    while (true) {
        workdays = safe_input_int();
        stavka = safe_input_double();
        
        if (workdays > 0 && workdays <= 7 && stavka > 0 && stavka <= 2.0) {
            break;
        } else {
            cout << "Ошибка! Рабочие дни: 1-7, ставка: 0.5-2.0. Попробуйте снова.\n";
        }
    }

    while (true) {
        cout << "Введите длительность рабочего дня в часах.\n";
        workinghours = safe_input_double();
        
        double correctworkinghours = standard_workinghours * stavka;
        double correctweekworkinghours = correctworkinghours * workdays;
        double weekworkhours = workdays * workinghours;
        
        if (!validate_input(workdays, stavka, workinghours)) {
            cout << "Попробуйте снова.\n";
            continue;
        }
        
        if (workinghours == correctworkinghours) {
            cout << "Данные введены правильно, приступайте к меню.\n" << endl;
            menu();
            break;
        } else {
            cout << "Ошибка! При " << workdays << "-дневной рабочей неделе " 
                 << workinghours << " часа в день составляют " << weekworkhours 
                 << " часов в неделю. Разница рабочего времени: " 
                 << correctweekworkinghours - weekworkhours << " (" 
                 << correctweekworkinghours/weekworkhours * 100 << "% от нормы ставки " 
                 << stavka << ").\n";
            cout << "Налицо факт предоставления заведомо ложных сведений работодателю. "
                 << "Попробуйте ввести снова.\n";
        }
    }
}

### Уязвимость 5: Бесконечные циклы и потеря управления потоком выполнения

Описание проблемы:

В функции premenu() вызов menu() не гарантирует корректное возвращение управления:

while (true) {
    // запрос данных
    if (workinghours == correctworkinghours) {
        cout << "Данные введены правильно, приступайте к меню.\n" << endl;
        menu();      // menu() содержит while(true)
        break;       // может быть недостижима!
    }
}

Функция menu() содержит собственный while(true):

while (true) {
    cout << "Добро пожаловать в меню!...\n";
    cin >> choice;

    switch (choice) {
        case 1: ... break;  // циклится обратно в while(true)
        case 5: ... break;
        case 6: {
            int answer;
            while (true) {
                cout << "Сколько в неделю часов работает лаборант на полставки?\n";
                cin >> answer;
                if (answer == 20) {
                    cout << "Правильный ответ, спасибо за использование!\n";
                    return 0;  // выход из программы, а не из menu()!
                }
            }
        }
    }
}

Тестовый ввод:
1. Выбрать опцию 1 (регламент) >> программа выводит информацию и возвращает в menu() while(true)
2. Выбрать опцию 2-5 много раз >> программа никогда не выходит из цикла menu()
3. Выбрать опцию 6 >> зависание в while(true) до правильного ответа
4. Ввести 20 >> return 0 закрывает всю программу, а не возвращает из menu() в premenu()

Потенциальные последствия:
- Программа может зависнуть в бесконечном цикле menu() и не вернуться в premenu()
- Невозможен корректный выход с сохранением данных или возвратом к предыдущему меню
- Срыв расписания занятий - программа зависает во время ввода и блокирует работу
- Потеря контроля над процессом - нельзя вернуться в premenu() после вызова menu()
- Невозможно переинициализировать рабочее время для другого лаборанта без перезагрузки

Изменить архитектуру управления
